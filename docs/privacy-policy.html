Política de Privacidade

Última atualização: 22 de fevereiro de 2026

1. Dados Coletados

O Compensa App é 100% offline-first. NÃO coletamos, armazenamos ou transmitimos dados pessoais a servidores externos.

Dados armazenados localmente no dispositivo:

  • Valores de economias registradas
  • Descrições de gastos evitados
  • Configuração de taxa de renda fixa
  • Cache de dados de mercado (preço BTC, taxa SELIC)

2. Dados de Mercado

O app faz requisições a APIs públicas (CoinGecko, Banco Central do Brasil) para obter dados de mercado. Essas requisições NÃO incluem dados pessoais. Nenhum identificador do dispositivo é enviado.

3. Terceiros

NÃO utilizamos: analytics, publicidade, SDKs de rastreamento ou crash reporting com dados pessoais.

4. Armazenamento e Segurança

Todos os dados ficam no sandbox do app, protegidos pelo sistema operacional do dispositivo. Não há backup em nuvem.

5. Compartilhamento

NÃO compartilhamos dados com terceiros.

6. Retenção e Exclusão

Os dados são retidos enquanto o app estiver instalado. Para excluí-los: desinstale o app ou exclua os registros individualmente dentro do aplicativo.

7. Crianças

O Compensa App não é direcionado a menores de 13 anos.

8. LGPD (Lei 13.709/2018)

Base legal: consentimento ao utilizar o app. Os dados são exclusivamente locais. Direito de exclusão via desinstalação ou exclusão de registros. Direito de acesso: todos os dados são visíveis diretamente no app.

9. Alterações

Reservamo-nos o direito de atualizar esta política. Alterações serão refletidas nesta página com a data de atualização revisada.
