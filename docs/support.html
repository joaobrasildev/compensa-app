Perguntas Frequentes

📱 Onde meus dados ficam salvos?

Todos os dados são armazenados localmente no seu dispositivo. Não enviamos nada para servidores externos. Se desinstalar o app, os dados serão apagados.

📊 De onde vêm as taxas de rendimento?

A taxa Selic é obtida da API pública do Banco Central do Brasil. O preço do Bitcoin vem da API pública do CoinGecko. As taxas são atualizadas automaticamente quando há conexão com a internet.

📶 O app funciona sem internet?

Sim! O app funciona offline usando os últimos dados de mercado em cache. Quando houver conexão, os dados são atualizados automaticamente.

🗑️ Como apagar meus dados?

Você pode excluir registros individualmente pelo histórico dentro do app, ou desinstalar o app para remover todos os dados.

💰 O app é gratuito?

Sim, o Compensa? é 100% gratuito. O app exibe anúncios não personalizados via Google AdMob para se manter.

⚠️ As simulações são garantia de rendimento?

Não. As projeções são estimativas baseadas em dados históricos e taxas atuais. Investimentos estão sujeitos a riscos e rentabilidade passada não garante resultados futuros.
